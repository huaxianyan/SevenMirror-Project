# 三端低保真原型

直接用浏览器打开 [index.html](index.html)，无需安装依赖或启动服务。当前目录的 HTML、CSS 和 JavaScript 需要保留在一起。

## 查看顺序

1. Android「应用」：图标、名称、包名、同名应用、搜索和显式保存。
2. 从应用行进入设置：核对单个应用的策略是否容易找到，底部归属「设置」。
3. Android「设置 → 权限与运行条件」：在左侧评审工具中选择「通知访问已撤销」，查看问题入口和返回授权后的状态示意。
4. Android「设置 → 接收设备」：选择工作或家用浏览器、保存空选择，再从首页查看已选摘要及重新选择入口。初始勾选只是已配置手机的示例，不表示首次使用会预选设备。
5. Android「同步」：切换已连接、断网、暂停和权限失效示例。
6. 浏览器扩展：通知列表 → 来源筛选 → 通知详情与回复 → 设置分区。
7. 服务端管理端：待处理申请 → 添加设备 → 设备详情。

左侧目录和场景选择是评审工具，不是正式产品导航。窄屏时评审工具移到页面上方。

## 原型边界

- 全部应用、包名、通知、设备、图标及状态均为虚构示例，符号图标只说明图标的位置与尺寸关系。正式应用列表将读取本机应用图标。
- 应用与接收设备选择只在当前页面内存中保留，刷新即重置。设置表单只演示控件、保存／放弃和未保存提醒，不实现持久化、策略继承计算或跨页面配置联动。
- 发送端按设备限制通知、快照、补发及新操作授权尚未实现。取消选择不能撤回此前发出或已排队的内容，原型没有远程清空能力。
- 暂停、授权返回、审批和加入码只演示页面状态，没有真实的设备、权限、身份或通知操作。说明反馈位于手机／网页框外，不是正式产品文案。
- 关于、外观、数据清理、首次加入完整流程、长回复独立窗口和维护页尚未展开。对应入口明确说明，不能视为已实现功能。
- 这是灰度布局稿，不是最终 Material 3 实现或完整无障碍、深色模式、国际化验收。
- 不引入生产模块，不访问服务，不保存凭据，不进入三个仓库的发布产物。
